# Microsoft Azure

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides online tools and services that organizations can use to create applications, store information, manage databases, and operate their IT systems through the cloud.

## Global Infrastructure

Azure has cloud infrastructure located in many countries and regions. Its infrastructure is organized into regions and data centers, which help organizations run their applications reliably. Companies can choose appropriate locations based on performance, availability, and data requirements.

## Cloud Management Console

The Azure Portal is Microsoft's online management platform for Azure services. It gives users one place where they can create and manage resources such as virtual machines, databases, storage accounts, applications, and networks.

## Four Core Services

**1. Azure Virtual Machines** – Provides virtual computers that can run applications using Windows or Linux.

**2. Azure Blob Storage** – Stores large amounts of files and other unstructured information such as pictures, videos, and documents.

**3. Azure SQL Database** – Provides a managed SQL database service that can be used for business applications.

**4. Azure Functions** – Allows developers to execute code based on events without having to manage physical servers.

## Three Advantages

**1. Microsoft Compatibility** – Azure works well with many Microsoft products and technologies.

**2. Scalable Infrastructure** – Businesses can increase or reduce resources depending on their workload.

**3. Worldwide Availability** – Azure provides infrastructure in many regions, allowing organizations to serve users in different locations.

## Typical Enterprise Use Cases

Businesses commonly use Azure for hosting applications, managing company databases, storing files, running Microsoft-based workloads, performing data analysis, developing software, and creating backup and disaster recovery systems.
