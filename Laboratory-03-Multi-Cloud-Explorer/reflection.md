# Checkpoint 8 – Mission Reflection

## 1. Which cloud platform impressed you the most?

The cloud platform that impressed me the most is **Google Cloud Platform (GCP)**. I was interested in its Artificial Intelligence, Machine Learning, data analytics, and Kubernetes services. I also liked how these tools can be used to create modern applications and process large amounts of information.

## 2. What similarities exist among AWS, Azure, and GCP?

AWS, Azure, and GCP all provide similar cloud computing services, including virtual machines, storage, databases, networking, and identity management. They also allow users to scale resources based on their needs. Although the services have different names, they can perform many of the same functions.

## 3. How do business requirements influence cloud platform selection?

Business requirements help determine which cloud platform is the most suitable for an organization. Factors such as budget, existing technology, security, scalability, performance, and the type of application must be considered. For example, Azure is a strong choice for a company that already uses Microsoft products, while GCP can be a good option for AI and data-related workloads.

## 4. What did you learn from acting as a Cloud Solutions Consultant?

Acting as a Cloud Solutions Consultant taught me how to analyze a client's needs before recommending a cloud platform. I learned that there is no single cloud provider that is best for every organization. The recommendation should be based on the client's goals, available resources, existing technology, and future plans.

My GitHub Cloud Computing Portfolio became more organized and informative after completing the mission. I learned how to create Markdown files, comparison tables, decision matrices, and cloud platform recommendations. I also gained more confidence in using GitHub to present technical research and document my understanding of cloud computing.
