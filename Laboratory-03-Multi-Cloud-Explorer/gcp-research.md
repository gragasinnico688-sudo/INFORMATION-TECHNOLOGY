# Google Cloud Platform (GCP)

## Brief Overview

Google Cloud Platform (GCP), also known as Google Cloud, is Google's collection of cloud computing services. It allows organizations to use computing power, storage, databases, networking, analytics, and artificial intelligence tools through the internet.

## Global Infrastructure

Google Cloud operates through a worldwide infrastructure made up of regions and zones. These locations allow companies to deploy their applications and store their information in different parts of the world. Google's global network also helps provide reliable communication between cloud resources.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud resources. Users can create projects, configure virtual machines, manage storage, monitor applications, and control other cloud services from the console.

## Four Core Services

**1. Compute Engine** – Provides virtual machines that organizations can use to run applications and workloads.

**2. Cloud Storage** – Provides cloud-based storage for files, backups, media, and other types of information.

**3. Cloud SQL** – Provides managed relational databases such as MySQL, PostgreSQL, and SQL Server.

**4. BigQuery** – Provides a platform for analyzing large amounts of data and creating useful business insights.

## Three Advantages

**1. Data Analytics** – Google Cloud provides powerful tools for processing and analyzing large amounts of information.

**2. Artificial Intelligence** – It offers various services that support machine learning and AI development.

**3. Scalable Resources** – Organizations can adjust their cloud resources according to their changing requirements.

## Typical Enterprise Use Cases

Organizations can use Google Cloud for data analysis, artificial intelligence projects, website hosting, application development, database management, file storage, and business data warehousing.
